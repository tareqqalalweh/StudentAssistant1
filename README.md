 Student Assistant

Your Academic Journey, Organized.

Student Assistant is a Java-based desktop application designed to provide students with a simple and organized way to manage their academic information.

Built with Java Swing and database connectivity, this project demonstrates the practical application of object-oriented programming, graphical user interfaces, and database integration.

 Key Features

*  Student Login — A dedicated interface for student authentication.
*  Database Integration — Connects the application to a database to manage student records.
*  Student Information — Supports student data such as ID, name, major, GPA, and completed credit hours.
*  Desktop GUI — Built using Java Swing.
*  Structured Architecture — Organized packages for the user interface, data access, model classes, and application entry point.

 Tech Stack

* Java — Core application logic
* Java Swing — Graphical user interface
* JDBC — Database connectivity
* SQL Database — Student data storage
* Apache NetBeans — Development environment

 Getting Started

Prerequisites

* Java Development Kit (JDK)
* Apache NetBeans IDE
* A compatible database and JDBC driver, if required

Installation and Setup

1. Open the repository on GitHub.
2. Click Code.
3. Select Download ZIP to download the entire repository.
4. Extract the downloaded ZIP file to your computer.
5. Open Apache NetBeans.
6. Select File → Open Project.
7. Navigate to the extracted project folder and open it.
8. Configure the database connection according to your local environment.
9. Build and run the application.

Note: The project is stored on GitHub as regular files and folders. You do not need to upload a ZIP file yourself; GitHub can generate a ZIP archive for visitors through the Code → Download ZIP option.
